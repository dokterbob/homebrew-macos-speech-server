# Dokterbob Macos-speech-server

## How do I install these formulae?

`brew install dokterbob/macos-speech-server/<formula>`

Or `brew tap dokterbob/macos-speech-server` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "dokterbob/macos-speech-server"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
